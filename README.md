# ToDo List

Веб-приложение для отображения списка задач, реализованное на Django.

## Описание

Проект представляет собой простой ToDo List, в котором задачи хранятся в базе данных и выводятся на отдельной странице.
Каждая задача содержит название, статус выполнения и дату создания.

Приложение демонстрирует базовую архитектуру Django: работу с моделями, представлениями (views), маршрутизацией (urls) и HTML-шаблонами.

## Функциональность

* вывод списка задач из базы данных
* хранение данных в SQLite
* отображение статуса выполнения задачи

## Структура

Проект состоит из основного приложения, конфигурации Django и шаблонов для отображения данных в браузере.

## Назначение

Учебный проект для понимания основ разработки веб-приложений на Django.
